# Security Policy

MADEPROOF — платформа верификации, и безопасность здесь — **основной продукт**,
а не опция. Если ты нашёл уязвимость — сообщи, пожалуйста, ответственно.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅ |
| < 0.1   | ❌ (pre-release) |

## Сообщение об уязвимости

**Пожалуйста, НЕ создавай публичный GitHub Issue для уязвимостей.**

Напиши приватно на **castefeudal@gmail.com** с темой `[MADEPROOF-SEC] ...` и
включи:

- затронутую версию/коммит;
- тип уязвимости (RCE, sandbox-escape, auth bypass, data leak, DoS...);
- шаги воспроизведения (PoC, если есть);
- ожидаемое vs фактическое поведение;
- предложенный фикс (если есть).

Ожидай подтверждение в течение 48 часов. Мы будем держать тебя в курсе
прогресса и скоординируем раскрытие после фикса и релиза.

## Область безопасности (что защищаем)

Архитектурные гарантии, которые нельзя нарушить (см. также
[docs/SECURITY.md](docs/SECURITY.md) и [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)):

1. **Runner изолирован**: исполняет целевые команды только внутри Bubblewrap-
   песочницы (non-root, нет сети по умолчанию, лимиты, kill по таймауту).
2. **Control plane не исполняет код**: API/web никогда не запускают команды
   целевого репозитория.
3. **Runner не имеет доступа к БД** и не имеет входящих портов — только
   outbound-поллинг с одноразовой кредой `mpr_...`.
4. **Sandbox fail-closed**: без сильной изоляции runner не работает (в проде).
5. **Никакого ложного VERIFIED**: инфраструктурный сбой = `ERROR`,
   self-reported evidence ≠ proof.
6. **Неизменяемость**: receipt'ы и завершённые run'ы нельзя переписать.
7. **Tenancy**: доступ к проекту/раннеру строго ограничен владельцем.
